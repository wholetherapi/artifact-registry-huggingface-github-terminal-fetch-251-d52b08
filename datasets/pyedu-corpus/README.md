# pyedu-corpus

A collection of Python education code and explanations, assembled for training
and evaluation of code assistants.

- **Size:** about 210M tokens
- **Composition:** code snippets, docstrings, tutorial prose and exercise
  solutions gathered from permissively licensed public repositories.
- **Schema:** `text` (string), `topic` (string), `source_repo` (string)
- **License:** Open Data Commons Attribution License 1.0 (SPDX: `odc-by`).

The collection is distributed as an attribution-only dataset; downstream
derivative works must keep the attribution notice and may be shared and adapted
for any purpose.
