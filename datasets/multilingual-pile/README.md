# multilingual-pile

Large multilingual pretraining corpus covering natural language and code in
46 languages.

- **Size:** about 3.1B tokens
- **Composition:** web text, source code and technical Q&A in 46 languages.
- **Schema:** `text` (string), `language` (string), `repo_name` (string)
